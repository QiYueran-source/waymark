Resolution: Custom fields are project-declared data with no field-name-specific behavior. Their basic type checks validate value shape only; they do not add reference resolution, authorization, or workflow semantics. Initial types are string, integer, boolean, and homogeneous list<T> whose elements match the declared scalar type; no nested lists/objects or mixed lists. Enum is a project convention over string, not a distinct runtime type. No special timestamp or reference type in v1. Fields are optional by default; required=true makes them mandatory. Unset optional fields are omitted from frontmatter; a simple static default may be configured and applied on creation. Clove's fixed frontmatter gives a reference for explicit types and strict field handling, but this configurable schema is Waymark-specific.
