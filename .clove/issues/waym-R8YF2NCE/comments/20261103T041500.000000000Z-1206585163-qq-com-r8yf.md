Resolution: Waymark adopts Clove's read-surface skeleton and substitutes its own field vocabulary. The read operations are `list`, `ready`, `blocked`, `query`, `search`, `show`, `stats`, `tree`, and `dep tree`; `list`, `ready`, and `blocked` share one filter set. There is no `children` command — `tree --depth 1` covers it — and no `leaves` command: `list --leaves` filters items with no children.

Filters shared by `list`/`ready`/`blocked`: `--status` (repeatable, any-of), `--category` (repeatable, any-of), `--owner`, `--field key=value` (repeatable, custom fields, AND), `--q` (case-insensitive substring over id and title only, never the body — the distinction from `search`), `--parent <id>`, `--leaves`, and `--archived` selecting archived-only. Ordering, projection and paging are shared too: `--sort`, `--desc`, `--limit`, `--offset`, `--fields`, `--compact`. `--limit` defaults to 100 for CLI and 50 for MCP, with `0` meaning no limit; `--offset` skips results. `--fields` projects a field list and `--compact` omits unset values. Pagination is offset-based over a snapshot: results are stable within one call, and callers should not treat offsets as a cross-call cursor.

Default ordering is `rank`: status group (open, then in_progress, then closed), then dependency topological order, then stable id. `--sort` also accepts `id`, `created`, `updated`, `title`, `status`, `category`, and any declared sortable custom field of string or integer type; `--desc` reverses the result.

`query` is the structured form of `list` and exists only in the CLI, where a JSON filter object is easier to express than a long flag chain; both call the same query engine. MCP exposes no separate `query` tool because its `list` arguments are already structured.

`search <text>` is a case-insensitive substring match over title and body, ranked title hits before body hits, then `updated` descending and id ascending. It returns matching work items only — no snippets or highlighting. `--q` remains the cheap filter that never reads a body.

`stats` reports the counting range explicitly (`active` or `archived`), plus the total, counts by status, counts by category, ready count and blocked count, and an optional `--top N` breakdown over one declared string custom field. It reports no throughput, no time series and no historical snapshots, because Waymark keeps no event log or durable index.

`tree` renders the parent hierarchy for an optional root with an optional `--depth`; `dep tree <id>` renders the dependency graph with `--depth` and `--flat`. Both are distinct views of distinct relations.

Every global query requires a complete fresh projection and fails with `INCOMPLETE_PROJECTION` rather than returning partial results; only `show` may read scoped. Clove's `--label`, `--type`, `--priority`, `--assignee`, `--synced`/`--unsynced`, `comments`, and `stats --history` have no Waymark equivalent because labels, type, priority, assignee, external references, comments and a durable index do not exist in the model.
